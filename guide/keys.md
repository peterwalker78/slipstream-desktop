# Every key

Super+/ shows this list inside Slipstream, whenever you forget one. Press Enter there for the tour: fourteen short lessons for anyone new to tiling, each one drawn happening on a miniature of the desktop.

These are the Windows style's keys, which Slipstream starts with. Settings → Shortcuts switches to the [Mac style](#mac-style) or the [Omarchy style](#omarchy-style); the list, the tour and the hints on screen then show that style's keys.

| Keys | What they do |
|---|---|
| Super, tapped on its own, or Super+S | App explorer |
| Super+Return, Super+E, Super+I | Terminal, files, Settings |
| Super+B | A new window of your default browser |
| Alt+Tab, Alt+Shift+Tab | Switch windows, dealt as a deck of glass |
| Alt+F4 | Close the window |
| Super+arrows | Move focus. Up from the top row goes into a docked window; from a floating or docked window they lead back to the tiles |
| Super+Alt+arrows | Move the window: it swaps places with the one that way, the two passing through each other. Under gravity, moving into the centre takes it. A floating window moves a step |
| Super+[ and ], with Shift for height | Resize, tiled or floating; under gravity, lighter and heavier |
| Super+R, Super+Shift+R | Turn the whole layout a quarter, clockwise or back |
| Super+F | Fill the tiling area, and back, in tiling or gravity |
| Super+M, Super+Shift+M | Minimise to a stream at the edge, bring back |
| Super+W | Dock the window to the bar, in front of every workspace; again, its next size of three |
| Super+Shift+W | Bring the docked window back down as a standard window |
| Super+H | Hide every window on the workspace; again, bring them back |
| Super+Shift+V, Super+Ctrl+V | Float the window or tile it; switch between floating and tiled windows |
| Super+D | Show the desktop, and back |
| Super+Tab | Bullet time |
| Super+T | Tiling or gravity; keep Super held to choose the arrangement |
| Super+1–9, Super+Ctrl+← → | Go to a workspace |
| Super+Shift+1–9, Super+Shift+← → | Move the window to a workspace |
| Super+P, Super+Shift+P | Next screen, move the window there |
| Super+Ctrl+P | Swap workspaces with the next screen, windows and all |
| Super+A, Super+N | Quick settings, notifications |
| Super+Y | Your plugins, in the same place in every style |
| Super+V | Clipboard history |
| Print, Super+Print, Super+Shift+S | Screenshot of the screen; snip a region or a window |
| Super+= and Super+-, Super+0 | Zoom in and out around the pointer; back to normal. Super and the wheel zoom too |
| Super+L | Lock |
| Super+Esc | Take the mouse and keys back from a game or virtual machine holding them |
| Alt+Shift, pressed together and let go | The next keyboard layout, once Settings → Mouse & keyboard has more than one |
| Caps Lock | Tap: Caps Lock. Hold: Awake, the screen stays on and doesn't lock; hold again or click AWAKE on the bar to end it |
| Ctrl+Alt+Del, Super+X | The way out: lock, log out, restart, shut down |
| Super+/ | Every key, and Enter there starts the tour |

The volume, mute, brightness and media keys work as marked, with any player that speaks MPRIS, and stay the desktop's even while a game holds every key. Ctrl+Alt+F1–F12 switch virtual terminals as usual. Keys that input methods, screen readers and games rely on are left alone.

## Mac style

Super is ⌘. Apps keep their own shortcuts, so copy and paste are still Ctrl+C and Ctrl+V. Super is not tapped for the explorer, and Ctrl+Space stays with input methods, as on a Mac. These are the keys that differ from the Windows style; Super+/ lists every one.

| Keys | What they do |
|---|---|
| Super+Space | App explorer |
| Super+Tab, Super+Shift+Tab | Switch windows (Alt+Tab works too) |
| Super+W, Super+Q | Close the window; quit the app, every window of it |
| Super+M, Super+H | Minimise to a stream |
| Super+Alt+M | Hide every window on the workspace, and back |
| Super+Ctrl+F | Fill the tiling area, and back |
| Super+Ctrl+↑ | Bullet time |
| Super+Ctrl+← → | Previous, next workspace |
| Super+Alt+1–9 | Move the window to a workspace |
| Super+Shift+3, Print | Screenshot of the screen |
| Super+Shift+4, Super+Shift+5 | Snip a region or a window |
| Super+Alt+= and Super+Alt+-, Super+Alt+0 | Zoom in and out; back to normal |
| Super+Ctrl+Q | Lock |
| Super+Shift+Q | The way out: lock, log out, restart, shut down |
| Super+, | Settings |
| Super+Alt+D, Super+Alt+Shift+D | Dock the window to the bar; bring it back down |

## Your own shortcuts

Settings → Shortcuts adds keys that open an app: choose the app, then press the keys. They can't be a key your style already uses, or one kept for typing aids, screen readers and games; Settings says which when you press one. Changing style keeps them. One the new style uses does nothing, and Settings says why, until you take it away or change back. Super+/ lists the ones that work.

## On a touchpad

The same in every style. Each swipe follows your fingers and finishes at your pace.

| Three fingers | What they do |
|---|---|
| Left, right | The next or previous workspace; in bullet time, look at the next one |
| Up | Bullet time |
| Down | Leave bullet time |

## Inside panels and bullet time

In any panel or card, Esc backs out one level, Tab and the arrows move, Enter presses, and Home, End, PgUp and PgDn jump.

| In bullet time | What they do |
|---|---|
| Arrows, Tab | Choose a window; every window in turn |
| The letter on a window | Jump to it |
| 1–9 | Look at a workspace |
| Enter | Go |
| Shift+1–9, Shift+← → | Send the window to a workspace, or the one beside |
| M, Del | Minimise, close |
| Esc | Back, with nothing changed |

Once the desktop has faded to the wallpaper, F7 saves a picture of it and any other key brings the desktop back.
